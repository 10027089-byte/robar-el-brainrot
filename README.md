# Robar el Brainrot

Juego 3D de exploración y plataformas: encuentra criaturas originales, llévalas a
tu base para conseguir créditos y compra mejoras para la siguiente expedición.

## Desarrollo

- `npm install`
- `npm run dev`
- `npm run build`

El proyecto usa Vite con `client/` como raíz y genera el paquete en `client/dist/`
para Boxity.

## Controles

- `WASD` o flechas: moverse
- `Espacio`: saltar
- `E`: recoger un hallazgo o depositar en la base
- `Q`: activar el escudo láser

En móvil aparecen controles táctiles en pantalla.
